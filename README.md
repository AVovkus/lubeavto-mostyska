# Любе Авто Мостиська — Вебсайт майданчика, калькулятор та кабінет менеджера

Адаптивний статичний сайт автомайданчика **«Любе Авто Мостиська»** з каталогом авто в наявності, фільтрацією, галереєю фотографій, фірмовим 3-колонковим калькулятором розмитнення та окремим кабінетом менеджера. Проєкт повністю готовий до безкоштовного хостингу на **GitHub Pages**.

## Структура проєкту

```text
lubeavto_site/
├── index.html          # Головна сторінка (шапка, банер, вітрина, калькулятор, галерея в модальному вікні)
├── admin.html          # Кабінет менеджера (додавання/редагування авто, фото, статуси, контакти, експорт)
├── supabase-setup.sql  # SQL-скрипт для опційної безкоштовної хмарної бази Supabase
├── .nojekyll           # Маркер для коректної віддачі статичних файлів на GitHub Pages
├── css/
│   ├── styles.css      # Основні стилі сайту та адаптивна верстка
│   └── admin.css       # Стилі кабінету менеджера
├── js/
│   ├── data.js         # Контакти, курси валют, конфіг Supabase і базовий каталог авто
│   ├── locations.js    # База з 534 майданчиків США та Канади з тарифами і портами
│   ├── calculator.js   # Формули розрахунку (аукціонні збори, доставка, море, акциз, мито, ПДВ, страхування)
│   ├── store.js        # Спільне сховище (IndexedDB/localStorage + опційний REST-клієнт Supabase)
│   ├── app.js          # Вітрина, фільтри, галерея у модальному вікні та інтерактивний калькулятор
│   └── admin.js        # Логіка кабінету менеджера
└── assets/
    └── img/            # Логотип, іконки та фотографії майданчика і авто
```

## Публікація на GitHub Pages (безкоштовно)

1. Завантажте вміст папки `lubeavto_site` у публічний репозиторій на GitHub (наприклад, на гілку `main`).
2. У репозиторії перейдіть у **Settings → Pages**.
3. У блоці **Build and deployment → Source** виберіть **Deploy from a branch**, оберіть гілку **`main`** та папку **`/ (root)`**, і натисніть **Save**.
4. Через 1–2 хвилини сайт запрацює за адресою вигляду `https://<ваш-логін>.github.io/<назва-репозиторію>/`, а кабінет менеджера буде доступний за адресою `/admin.html` (посилання також є у футері головної сторінки).

## Як користуватися кабінетом менеджера (`admin.html`)

### Режим 1: Локальний режим + експорт `js/data.js` (без налаштування бази)
- Відкрийте `admin.html`.
- Стандартний пароль для входу в локальному режимі: **`lubeavto2026`** (змінити його можна у вкладці «Контакти та курси», або в `js/data.js` → `adminLocalPassword`).
- Додайте або відредагуйте авто, завантажте кілька фото чи відео (також підтримуються посилання на YouTube або MP4; фото автоматично стискаються перед збереженням), змініть статуси (`В наявності`, `В дорозі`, `Бронь`, `Продано`), оновіть контакти чи курси.
- **Важливо:** у локальному режимі без бази дані зберігаються лише у вашому браузері (через `IndexedDB` / `localStorage`). Щоб оновлення побачили всі відвідувачі на GitHub Pages:
  1. Перейдіть на вкладку **«GitHub Pages та Хмара»**.
  2. Натисніть **«Завантажити оновлений js/data.js»**.
  3. Замініть файл `js/data.js` у репозиторії GitHub і зробіть commit/push.

### Режим 2: Хмарний режим із безкоштовним Supabase (оновлення напряму з телефону чи ПК)
1. Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
2. Відкрийте **SQL Editor → New query**, вставте та виконайте весь скрипт із файлу [`supabase-setup.sql`](supabase-setup.sql) — він створить таблиці `cars`, `site_settings`, непублічну схему `private` (`admin_users`), бакет `car-photos` і захищені RLS-політики (`private.is_lube_admin()`).
3. У розділі **Authentication → Providers → Email** вимкніть публічну реєстрацію (**Allow new users to sign up**), а у **Authentication → Users → Add user** створіть обліковий запис менеджера (email + пароль).
4. У **SQL Editor** додайте цей самий email менеджера до таблиці доступу:
   `insert into private.admin_users (email) values ('ваш-email@gmail.com') on conflict do nothing;`
5. У файлі `js/data.js` впишіть `url` та `anonKey` у секцію `window.LUBE_AVTO_CONFIG.supabase`.
6. Оновіть `js/data.js` (через Git або прямо на GitHub). Після входу в `admin.html` у вкладці **«GitHub Pages та Хмара»** можна в один клік натиснути **«Перенести локальні авто в Supabase»**, щоб перенести вже додані авто з ПК у хмару.

## Локальний запуск

Сайт побудовано на чистому HTML/CSS/JS без збирачів:
- Відкрийте `index.html` або `admin.html` напряму у браузері.
- Або запустіть локальний сервер у папці проєкту, наприклад: `npx serve .`
