# Любе Авто Мостиська — Вебсайт майданчика та калькулятор

Адаптивний сайт-вітрина автомайданчика **«Любе Авто Мостиська»** з каталогом авто в наявності, фільтрацією, детальними картками та фірмовим 3-колонковим калькулятором вартості авто з аукціонів США та Канади.

## Структура проєкту

```text
lubeavto_site/
├── index.html          # Головна сторінка (шапка, банер, вітрина, 3-колонковий калькулятор, футер, модальне вікно)
├── css/
│   └── styles.css      # Стилі та адаптивна верстка
├── js/
│   ├── data.js         # Контакти, курси валют та список автомобілів на майданчику
│   ├── locations.js    # Повний список 534 майданчиків США та Канади з тарифами доставки і портами
│   ├── calculator.js   # Логіка розрахунку (аукціонні збори, доставка, море, акциз, мито, ПДВ, страхування)
│   └── app.js          # Рендер карток, фільтри, модальне вікно та інтерактивний калькулятор
└── assets/
    └── img/            # Логотип, іконки та фотографії майданчика і авто
```

## Як оновлювати контент

1. **Контакти та курси валют** — відкрийте `js/data.js` та змініть значення у `window.LUBE_AVTO_CONFIG`:
   - `phoneDisplay` і `phoneHref` — номер телефону для шапки, футера та модальних вікон.
   - `telegramUrl` — посилання на менеджера в Telegram.
   - `rates.usdToUah` та `rates.eurToUsd` — курси валют (за замовчуванням `EUR/USD = 1.11`).
2. **Локації аукціонів (`window.AUCTION_LOCATIONS`)** — повна база з 534 майданчиків США/Канади міститься у `js/locations.js`; також у калькуляторі є пункт **«Інший майданчик (ввести суму вручну)»**.
3. **Додавання нового авто на майданчик** — покладіть фото в `assets/img/` та додайте новий об'єкт у масив `window.CARS_DATA` у `js/data.js`.

## Локальний запуск

Сайт працює на чистому HTML/CSS/JS без збирачів:
- Відкрийте `index.html` безпосередньо в браузері.
- Або запустіть локальний сервер у папці проєкту: `npx serve .`
