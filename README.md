# Режим технічних робіт (`global_works`) — Любе Авто Мостиська

Окрема гілка для тимчасового переведення сайту в режим технічного обслуговування на GitHub Pages.

## Як увімкнути технічні роботи
1. Відкрийте репозиторій на GitHub → **Settings → Pages**.
2. У блоці **Build and deployment → Branch** змініть **`main`** на **`global_works`** (папка **`/ (root)`**) і натисніть **Save**.
3. Через 1–2 хвилини відвідувачі сайту бачитимуть повідомлення про технічні роботи з актуальними контактами, а файл підтвердження Google (`google701ebee62fea4a7d.html`) продовжить працювати.

## Як повернути основний сайт
1. Відкрийте **Settings → Pages**.
2. У блоці **Branch** змініть **`global_works`** назад на **`main`** (папка **`/ (root)`**) і натисніть **Save**.
