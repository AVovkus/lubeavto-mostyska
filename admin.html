      Публікація змін на GitHub Pages

      Якщо ви користуєтеся сайтом на GitHub Pages без підключеної хмарної бази, додані тут авто зберігаються лише у вашому браузері. Щоб їх побачили всі клієнти:

      1. Додайте потрібні авто та фото на вкладці «Авто на майданчику».
      2. Натисніть кнопку нижче, щоб завантажити оновлений файл data.js.
      3. Замініть файл js/data.js у вашому GitHub-репозиторії (через Git або інтерфейс GitHub).

      Підключення безкоштовної хмари (Supabase)

      Наразі хмара не підключена. Коли створите безкоштовний проєкт у Supabase, менеджер зможе додавати авто прямо з телефону без оновлення файлів у GitHub.

      1. Створіть безкоштовний проєкт на supabase.com.
      2. Виконайте в SQL Editor скрипт із файлу supabase-setup.sql та додайте email менеджера в таблицю private.admin_users.
      3. У розділі Authentication → Providers → Email вимкніть публічну реєстрацію та створіть користувача менеджера у Users.
      4. Впишіть url та anonKey у секцію supabase файлу js/data.js.
